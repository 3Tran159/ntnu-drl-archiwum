Continue without an active Work session

The local Python service, controller and STAR macros run on this computer. Keep the computer powered and awake. Opening the dashboard starts no calculation.

Current campaign: Waiting for the other agent's mesh convergence and optimization results before any C01 or wave launch.

1. Point to your prepared mesh

Paste an absolute path to an existing .sim, for example your M11 file, and click Inspect mesh. This creates a separate copy on E: and performs a CPU inspection with zero flow steps. It records cell count, domain, timestep, boundary names, quality and one-span topology. The source file stays untouched. Wait for the inspection result, then select the imported copy.

Mechanical compatibility does not establish mesh convergence. Review the other agent's study before enabling flow. Unsupported inputs display what needs to be changed; edit a separate file in STAR and inspect it as a new input.

2. Choose a wave and domain

Select H, wavelength, upstream/downstream distances, wall-time limit and checkpoint interval. The timestep is read from the selected file. A new mesh, domain or numerical profile requires its own C01. The local builder preserves the selected foil/prism coordinates and checks the new remote geometry before any flow. It initializes a fresh flat-water copy; previous imported fields do not count as settled C01.

3. Save the queue, then enable it explicitly

Save configuration only records a request. Release campaign hold only enables future starts. Neither starts a solver. If the readiness list requests it, Check recipe performs a separate zero-flow CPU API inspection. Once the checks pass and you are ready, click Start queued jobs. The sequence is matching C01, computed settled save, full-height inlet wave, cycle assessment and saved result.

4. Watch, stop and continue

Current mesh study: use the separate Mesh calculation pause and resume buttons near the top. Pause finishes the current step and saves. Wait for Paused and saved before unplugging. Resume continues the saved mesh campaign with its existing settings and histories; it does not release the separate wave-campaign hold.

The main dashboard shows the current case, CL/CD, latest physical time, arrival/period estimates, saved side view, CPU/GPU state and diagnostics. A view labelled with a saved time is a snapshot, not a continuous field animation.

Stop, save and pause queue waits for a step boundary and writes the calculated fields. Do not disconnect power before the saved file appears. Continue saved run queues a new attempt from a verified normal-stop checkpoint; press Start separately. A physical-guard failure cannot use ordinary continuation.

Checkpoints default to every0.05s of simulated time. Frequent full .sim files use disk space and add save time; the controller stops if resources become insufficient. You can choose0.05-1s for future jobs.

5. Select results in the combined report

Use Mesh assessment for mesh, pressure and streamline previews. Use Waves for the current CL/CD history, cycle overlays, convergence and the saved free surface. Finished or stopped runs move to the collapsed archive and leave the live area ready for the next case.

CL excludes buoyancy: the audited hydrostatic buoyancy is subtracted from vertical force before normalization. The original force and CL_total history remain preserved. If the case lacks verified geometry or physical reference values, corrected CL is unavailable rather than estimated.

Open the combined report and choose the cases to display. Use CL/CD histories for startup and oscillations, fixed-phase cycle overlays for repeatability, and the convergence/diagnostic tables for context. A repeatability pass is not a mesh/time/propagation accuracy claim. Failed and incomplete runs retain their labels and diagnostic files.
