 Activating Implicit Unsteady and Rigid Body Motion For this case Simcenter STAR-CCM+ actually rotates the mesh for the Rotating region in an unsteady simulation. Hence, you activate one of the unsteady models and thereafter apply a rotational motion to the region that contains the fan blades. For the physics continuum, Physics 1 : From the Enabled Models box, deactivate the Steady model. From the Time box, select Implicit Unsteady , then click Close . Now you create a motion that uses the rigid body motion method and apply this new motion to the Motion Specification node of the rotating region. Right-click the Tools > Motions node and select New > Rotation . A new Rotation node is added to the Motions node. To set up the rotation motion: Select the Motions > Rotation node and make sure that Rotation Specification is set to Rotation Rate (default). Select the Rotation > Rotation Rate node and set Rotation Rate to 2000 rpm . Select the Rotation > Rotation Axis node and set Direction to [0.0,0.0,1.0] . Apply this motion to the rotating region, and change the reference frame for the region to the stationary default frame. Select the Regions > Rotating > Physics Values > Motion Specification node and set Motion to Rotation . Selecting this motion results in the Reference Frame property automatically reverting to the default Lab Reference Frame . Save the simulation.
