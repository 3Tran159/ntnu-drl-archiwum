 Creating a 2.5D Mesh with the Surface and Volume Extruders To create a 2.5D mesh, you can apply a surface and a volume extruder based on an existing parts-based volume mesh. To apply the surface and volume extruders, ensure that a volume mesh already exists in the meshing pipeline. You apply a surface extruder to generate bounding surfaces for the extruded one-cell-thick mesh and then fill the bounding surfaces with volume cells using a volume extruder. To set up the surface extruder: Right-click the Geometry > Operations node and select New > Surface Preparation > Surface Extruder . In the Create Surface Extruder Operation dialog, populate the following properties: Property Setting Input Parts The entire simulation domain from the input geometry Input Part Surfaces The surface you want to extrude Create New Part Single New Part (default) Output Part Surfaces All Pertinent Sides (default) Extrusion Distance The thickness of the cell layer in the third direction. Note To generate a 2D mesh for the Input Part Surfaces , the surface extruder takes over the meshline pattern from the 3D mesh you started with and extends the edges outward to form closed bounding surfaces of the entire extruded region. Later on, the volume extruder fills the bounding surface with volume cells. To modify the corner meshline pattern at the corners of the 2D mesh applied on the Input Part Surfaces , select the Operations > Surface Extruder node and change the settings for Grid Type . See Grid Type . Select the Surface Extruder > Controls > Direction Mode node and set Direction Mode to Surface Normal . Right-click the Surface Extruder node and select Execute . To fill the volume cells for the 2.5D mesh, apply a volume extruder as follows: Right-click the Geometry > Operations node and select New > Mesh > Volume Extruder . In the Create Volume Extruder Operation dialog, select Surface Extruder as Parts . The shape of the extruded region is fully defined in the surface extruder. In the volume extruder, you only specify the number of cell layers in the extrusion direction. Select the Operations > Volume Extruder > Controls > Number of Layers node and set the Number of Layers to 1 . Multi-select the boundaries on both sides of the one-cell-layer and set the Type to Symmetry Plane . Note In most of the cases, 2.5D mesh is used to represent a 2D mesh when a 2D mesh is incompatible with the mesh or physics models. You set the two side surfaces as symmetry planes, which are planar "slip walls" without any influence on the flow nearby. Right-click the Operations > Volume Extruder node and select Execute .
