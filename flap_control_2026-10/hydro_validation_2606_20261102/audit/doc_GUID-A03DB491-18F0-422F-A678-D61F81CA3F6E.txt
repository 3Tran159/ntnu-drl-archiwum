 Clear Solution Clear Solution resets simulation storage according to options that you select from its properties. The operation is typically applied at the start of a sequence. Properties Clear History Clears the current iteration number and time (for an unsteady case), as well as all monitors and residual plots. This option is activated by default. Clear Fields Clears all data fields from the solution. To maintain the data fields so that they remain in place as initial conditions, deactivate this option. If you selected a motion model, the initial position of the mesh is also cleared when this option is activated, so that you can modify the initial mesh position before commencing the next simulation. Reset Mesh This option is only available when you have selected a motion model or a turbulence model. If a motion model is active, activate this option to reset all mesh vertices to the their Initial Position Storage, that is, the saved vertex positions at time zero. However, if the simulation has already run, and if in the saved simulation file you executed a remesh with current position of a moving part or manipulate the region by adding a new region or deleting, splitting, merging the existing regions. The Initial Position Storage at time zero will be overwritten by the new positions at the time when the remesh or the region manipulation happened. i.e, the vertices can not move back to their very initial positions at time zero. If a turbulence model is active, this option clears the wall distance solution. Clear Transform Clears the effect of transforms for displayers. For more details, refer to Using Transforms . Clear Adaption Only applies when you have selected the Adaptive Mesh model. Clears the adaption control data which registers how cells are subdivided during adaptive mesh refinement. The Reset Mesh option should be selected simultaneously when you want to reset the mesh back to its initial state. Once the adaption control data is cleared it is not possible to return the mesh to its initial state. Clear Lagrangian Only applies when you have selected the Lagrangian Multiphase Model. Clears all Lagrangian particles from the solution. Clear Adjoint By activating this option you clear only the adjoint solution, but not the primal solution (which comes under Clear Fields ). Once the Clear Fields option is activated, you do not need to activate Clear Adjoint , because both primal and adjoint solutions are deleted with Clear Fields . Clear Recorded Solution History Clears data from all solution history files connected to the simulation. This option is activated by default. Clear Normal Modes Clears the normal modes results data of the solid structures calculated by the Solid Stress Normal Modes solver. Clear Acoustic Modes Clears the acoustic modes results data for the CFD solution of a given geometry calculated by the Acoustic Modal solver.
