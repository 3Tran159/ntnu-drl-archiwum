 Volume Extruder The volume extruder fills in the extruded region with extruded volume cells from the input surface. You control the amount of divisions in the extruded region the volume extruder operation. You must have a volume mesh set up in parts to use the extruder in parts. For information on how to use the extruder mesher in parts, see Using the Extruder in Parts . Volume Extruder Properties Parameter Description Input Parts Specifies the part that acts as the source for the extruder. The input part must be a Surface Extruder part. Auto-Retraction When activated, runs a check for intersections and retract the volume if necessary. Volume Extruder Controls Parameter Description Number of Layers Specifies the number of cells in the direction of extrusion. The default value is 1, which is the minimum. There is no maximum limit to the number of layers allowed. Stretching Method Specifies the spacing between the layers. Constant extrudes in a specified direction with constant thickness layers. One Sided Geometric uses geometric progression to compute cell thickness. One Sided Hyperbolic uses a hyperbolic stretching law to compute the cell distribution growth in the direction of the extrusion. This option is geared specifically for aerospace and other applications where the boundary layer resolution is considered critical. Two Sided Hyperbolic uses hyperbolic stretching from both ends to compute cell distribution. Volume Extruder Stretching Options Parameter Description Stretching > Stretch Value Specifies the ratio of spacing at layer n and layer n+1. Initial Wall Thickness > Initial Wall Thickness Specifies the thickness of the first layer of cells near the input part surface. Thickness Ratio > Thickness Ratio Specifies the layer spacing between the first layer and the last layer of cells.
